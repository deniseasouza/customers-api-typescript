# Customers API — TypeScript + Fastify + Prisma

REST API for customer management, written in TypeScript with a controller/service split, Fastify as the HTTP layer and Prisma over MongoDB.

## Overview

A small CRUD service built to practise layered architecture in Node:

- **Routes** (`src/routes.ts`) register the endpoints as a Fastify plugin.
- **Controllers** parse and validate the request, then delegate.
- **Services** hold the business rules and are the only layer that talks to Prisma.
- **Prisma client** (`src/prisma/index.ts`) is instantiated once and shared.

Errors bubble up to a global Fastify error handler that answers `400` with the message, so no route repeats try/catch.

## Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/teste` | Health check |
| `POST` | `/customer` | Creates a customer (`name`, `email`; `status` defaults to `true`) |
| `GET` | `/customers` | Lists customers |
| `DELETE` | `/customer?id=<id>` | Deletes a customer by id |

## Data model

```prisma
model Customer {
  id         String    @id @default(auto()) @map("_id") @db.ObjectId
  name       String
  email      String
  status     Boolean
  created_at DateTime? @default(now())
  updated_at DateTime? @default(now())

  @@map("customers")
}
```

## Tech stack

`TypeScript` · `Node.js` · `Fastify 5` · `Prisma 6` · `MongoDB` · `@fastify/cors` · `dotenv` · `tsx`

## How to run

```bash
npm install
cp .env.example .env   # then fill in your own MongoDB connection string
npx prisma generate
npm run dev
```

The API listens on `http://localhost:3000`.

Quick check:

```bash
curl -X POST http://localhost:3000/customer -H "Content-Type: application/json" -d '{"name":"Ada","email":"ada@example.com"}'
```

## Notes

`src/generated/` (the Prisma client) is intentionally not versioned — it is regenerated by `npx prisma generate`, and it includes a platform-specific query-engine binary. `.env` is git-ignored; use `.env.example` as the template.
